My code analyzes Landsat satellite images to identify varying types of land use and land cover in Baldwin County, Alabama. By utilizing NDVI, NDBI, and NDWI thresholds as well as the geopandas, numpy, rioxarray, and matplotlib packages, this code can determine areas predominantly covered by vegetation, water, and urbanized environments. The results are then plotted to compare and contrast LULC changes in over a varying timescale. This code can be applied to any other county as long as there's appropriate Landsat coverage for the area.
